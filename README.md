# Portfolio — Cristian Pottier

Portfolio personnel présentant mes projets en ingénierie des médias (HEIG-VD).

🔗 [cristianpottier.ch](https://cristianpottier.ch)

## Stack technique

- Vue 3 (Composition API, `<script setup>`)
- Vite
- Vue Router
- Tailwind CSS v4

## Développement local

    npm install
    npm run dev

L'application tourne sur `http://localhost:5173`.

## Build

    npm run build

## Structure

    src/
    ├── assets/        # styles globaux
    ├── components/    # Nav, Contact, GridBackground...
    ├── data/          # contenu des projets (projects.js)
    ├── router/        # configuration des routes
    └── views/         # HomeView, ProjectView
